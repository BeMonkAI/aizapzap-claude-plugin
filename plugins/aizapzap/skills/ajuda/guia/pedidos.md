# Pedidos
Link: https://aizapzap.com.br/dashboard/orders
Para quem: restaurante e marca local.

## Para que serve
Lista os pedidos que a IA fechou pelo WhatsApp. Você acompanha cada um e avança o status conforme o pedido anda. Não há criação manual de pedido.

## Como usar
1. Abra a página e veja os pedidos do mais novo para o mais antigo.
2. Em cada pedido há o cliente, os itens, o total e se é entrega (com endereço) ou retirada.
3. Use o botão de avanço para mudar o status: Novo, Confirmado, Preparando, Pronto, Entregue.
4. Para cancelar, use "Cancelar" enquanto o pedido não estiver entregue.
5. Filtre por status no seletor do topo.

## Dúvidas comuns
- **Um pedido entregue pode voltar?** Não. "Entregue" e "Cancelado" são finais.
- **Posso pular etapas?** O botão oferece só o próximo passo e o cancelamento.
- **Quantos pedidos aparecem?** Os 100 mais recentes.
- **A IA não está pegando pedidos.** Confira se há entrega ou retirada ligada no Perfil e se os itens têm preço no cardápio ou catálogo.
- **Entregar um pedido gera pontos?** Se a fidelidade estiver ativa, sim: o pedido entregue credita pontos ao cliente.
- **Por que vejo "Pedidos não disponíveis"?** O seu tipo de negócio vende horários, não pedidos.

## English
Orders lists what the AI closed on WhatsApp. You move each order forward (New, Confirmed, Preparing, Ready, Delivered) or cancel it before delivery. Orders cannot be created by hand. Restaurants and local brands only.
