# Influenciadores
Link: https://aizapzap.com.br/dashboard/influencers
Para quem: todos.

## Para que serve
Cada influenciador ganha um código e um link de WhatsApp. Quem chega pelo código fica ligado a ele: a conversa, o cliente novo e os pedidos. A tabela mostra os resultados de cada um.

## Como usar
1. Em "Novo influenciador", preencha o nome, o Instagram (opcional), o código (mínimo 3 caracteres) e o desconto em % (opcional).
2. Clique em "Cadastrar".
3. Na tabela, clique em "Copiar link" e envie ao influenciador.
4. Acompanhe conversas, clientes novos, pedidos, receita e recompra.
5. Use a chave "Ativo" para pausar um código e a lixeira para excluir.

## Dúvidas comuns
- **Como é o código?** Só letras sem acento e números, em maiúsculas, até 20 caracteres. O painel ajusta o que você digita.
- **O link não aparece.** Ele só é gerado se houver número de WhatsApp configurado na página WhatsApp.
- **O que o link faz?** Abre o WhatsApp com uma mensagem pronta citando o influenciador e o código.
- **A quais itens vale o desconto?** Aos itens dos pedidos feitos na conversa que começou com o código. Vai de 1 a 100%.
- **O que conta na receita?** Não entram a taxa de entrega nem os pedidos cancelados. "Recompra" são clientes trazidos com 2 ou mais pedidos.
- **E se eu excluir?** As vendas já atribuídas deixam de aparecer no relatório. Código repetido é recusado com o aviso "Esse código já existe".

## English
Influencers gives each person a code and a WhatsApp link. Conversations, new customers and orders that arrive with the code are credited to them, with an optional discount. The report excludes delivery fees and cancelled orders, and deleting an influencer removes their sales from the report.
