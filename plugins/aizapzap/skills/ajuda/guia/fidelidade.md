# Fidelidade
Link: https://aizapzap.com.br/dashboard/loyalty
Para quem: todos.

## Para que serve
Define a regra de pontos do seu programa de fidelidade e mostra o saldo de cada cliente. Os pontos entram sozinhos: quando um pedido é entregue ou quando um atendimento é iniciado. Você só registra o resgate da recompensa.

## Como usar
1. Ligue "Programa ativo".
2. Defina "1 ponto a cada (R$ gastos)", os "Pontos por visita", os "Pontos para a recompensa" e descreva a recompensa (ex.: um corte grátis).
3. Clique em "Salvar regra".
4. Em "Saldo por cliente", veja pontos e quantos faltam para a recompensa.
5. Quando o cliente alcançar a meta, clique em "Registrar resgate" na linha dele.

## Dúvidas comuns
- **Pedidos antigos geram pontos?** Não. Pedidos e visitas anteriores à ativação não pontuam.
- **Como os pontos de pedido são contados?** Pelo valor total do pedido entregue, dividido pelo valor de "1 ponto a cada". A regra padrão é 1 ponto a cada R$ 10.
- **E em negócios de horário?** Cada atendimento iniciado dá os "Pontos por visita" (padrão 1).
- **Um pedido pode pontuar duas vezes?** Não. Cada pedido e cada atendimento pontuam uma única vez, mesmo se o status mudar de novo.
- **O que o resgate faz?** Desconta do saldo a quantidade de pontos da meta. O botão só libera quando o cliente atinge a meta, e usa a regra já salva.
- **Mudei a regra, e os saldos?** Os saldos já lançados ficam como estão. A nova regra vale para os próximos pontos.

## English
Loyalty lets you set the points rule and see each customer's balance. Points are credited automatically when an order is delivered or an appointment starts, only after the program is switched on. You register redemptions by hand once a customer reaches the goal.
